# CATCH NOTE!

> Unity 기반 2D 이동형 리듬 액션 게임

Catch Note는 음악의 리듬에 맞춰 노트를 처리하며 필드 위를 이동하는 2D 리듬 액션 게임입니다.

플레이어는 필드 내에서 캐릭터를 상, 하, 좌, 우로 이동시키며 등장하는 노트를 정확한 타이밍에 처리해야 합니다.

또한 스토리 모드를 통해 NPC와 상호작용하며 게임을 진행할 수 있으며, 이동형 리듬 게임 플레이와 간단한 어드벤처 요소를 함께 즐길 수 있습니다.

### 게임 특징

#### 리듬 플레이

* 음악에 맞춰 노트를 처리하며 캐릭터 이동
* 이동 경로 예측 요소 제공

#### Long Note 시스템

* 이동 경로를 따라 진행되는 롱노트
* 방향 전환이 포함된 다양한 패턴 제공

#### 판정 시스템

* Perfect / Good / Bad / Miss 판정 제공
* 사용자 입력 오차를 고려한 판정 보정 기능

#### 스토리 모드

* NPC와의 상호작용
* 컷씬 및 대화 연출
* 스테이지를 따라 진행되는 게임 구조

<br>

### 조작 방법

| 입력 | 기능     |
| -- | ------ |
| W  | 위 이동   |
| A  | 왼쪽 이동  |
| S  | 아래 이동  |
| D  | 오른쪽 이동 |
